# assembly-Projects

A short dive into x86 assembly to find out - firsthand - how hard low-level programming actually is.

## What's here

- **HelloWorld/** - basic output
- **Calculator/** - integer addition

## Status: intentionally stopped

The goal was to see how hard assembly is. The current calculator does addition, but only up to 9+9 - which was a crazy thing to realise while implementing it. That was enough to answer my question: yes, it is genuinely hard. It's possible, but a time sink. I'm sticking with C. Thanks.
